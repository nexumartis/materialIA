# Frontend legacy (archivado)

Estas páginas estáticas fueron el primer frontend de Presupuesto Vivo:

- `vendedor.html` — panel de oportunidades.
- `sandbox_ui.html` — chat de demostración.
- `assets/pv.css`, `assets/pv-shell.js` — estilos y shell compartidos (sistema sobrio TasteSkill).

**Quedaron reemplazadas por la app React + TypeScript en `../web/`.** Se conservan como
referencia y como fallback sin build (se abren directo con `file://`, apuntando a la API en
`http://127.0.0.1:8077`). El frontend vigente y el que se mantiene es `web/`.
